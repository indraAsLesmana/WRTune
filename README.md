# WRTune Support & Issue Tracker
  
WRTune is a free companion app for OpenWRT routers. It provides a user‑friendly interface for device management, traffic monitoring, and system health — without requiring extra packages on vanilla OpenWRT.  
  
This repository is for **community support and feedback only**. you can use this repo to:  
 - Report bugs or problems  
 - Request new features  
 - Ask questions about usage  
  
 🔧 Blocking devices: WRTune requires permission to create firewall rules. All rules are organized under the prefix `wrtune_xxx` to keep your configuration clean and easy to manage.  
  
 📱 Availability: Android version is currently in **Preview on Google Play Store**. iOS release is ready but pending funding for the Apple Developer Program subscription.


## How to Report an Issue
- Go to the [Issues tab](../../issues)
- Click **New Issue**
- Choose the template (Bug Report / Feature Request)
- Provide details so we can help
