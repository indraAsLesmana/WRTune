# WRTune

**The User-Friendly Companion for OpenWRT**

WRTune simplifies your network management with a beautiful, modern interface. Monitor traffic, manage devices, and check system health—all without installing heavy packages on your router.

## 🛠 Support & Issue Tracker

This repository is the central hub for community feedback.

### How to Report an Issue
1.  Check the **[Troubleshooting Guide](docs/troubleshooting.md)** first.
2.  Search existing **[Issues](../../issues)** to see if your problem has already been reported.
3.  If not, click **[New Issue](../../issues/new)** and choose a template:
    - **Bug Report**: Something isn't working as expected.
    - **Feature Request**: You have an idea for a new capability.

### ⚠️ Important Notes
- **Permissions**: WRTune requires permission to manage firewall rules (prefixed with `wrtune_`) for features like device blocking.
- **Availability**: 
  - **Android**: Available on [Google Play Store](https://play.google.com/store/apps/details?id=com.wrtune.app) (Preview).
  - **iOS**: Coming soon (pending Apple Developer Program funding).
